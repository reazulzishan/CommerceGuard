# CommerceGuard

ML-based e-commerce risk intelligence, built from scratch in public. Predict risk. Understand behavior. Reduce preventable losses.

## Episode 1 · Will this order arrive on time?
Notebook: `notebooks/01_commerceguard_delivery_risk.ipynb` (generated by `notebooks/make_notebook.py`).

- Data: [Olist Brazilian E-commerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (~100k real orders). Put the CSVs in `data/raw/`.
- One row per order, checkout-time features only, chronological 70/15/15 split, test used once, July 2018 locked as a fresh holdout.
- Late-delivery classifier (Logistic Regression baseline, LightGBM, isotonic calibration, SHAP).
- Promise-date model (LightGBM quantile regression), compared with Olist's own promised date.

Results on the untouched July 2018 month (6,156 orders, 3.4% late):

| | PR-AUC | Mean promise | Late rate |
|---|---|---|---|
| Random | 0.034 | | |
| Olist's promise | | 20.3 days | 3.4% |
| CommerceGuard (Exp 2) | 0.066 | 17.0 days | 5.8% |

Limits: Brazilian data, not COD/Bangladesh; "late" is not "failed delivery"; only 3.1% of customers order twice, so customer history is nearly empty. Next: COD failure with real merchant data.
